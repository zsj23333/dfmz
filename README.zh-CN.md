# PEARL — 黄浦江上的夜

[English](README.md) | 中文

> **在线体验：[https://zsj23333.github.io/dfmz/](https://zsj23333.github.io/dfmz/)**

一个单页电影级 WebGL 夜景，从黄浦江上驶向东方明珠。基于 [kage](https://github.com/MengTo/kage) 的程序化 Three.js 滚动体验：不依赖任何外部图片或视频——东方明珠、江面、陆家嘴天际线、外滩、光晕和文字标识全部由代码实时生成。

## 运行

```bash
python -m http.server 8123 --bind 127.0.0.1
# 然后打开 http://127.0.0.1:8123/index.html
```

直接从文件系统打开 `index.html` 也可以（所有资源都是本地相对路径），但本地服务器可以避免浏览器文件访问的限制。

## 项目结构

```
index.html            单文件站点（标记、CSS、场景代码、后期处理管线）
runtime/three.min.js  本地 three.js 构建
runtime/fonts.css     Onest 字体（base64，本地）
PROMPT.md             生成此项目的构建提示词
PROMPT.template.md    从 kage 的 PROMPT.md 抽象出的通用模板
```

## 章节（相机路径）

| # | 章节 | 你看到的 |
|---|------|----------|
| 00 | The Crossing | 江面上的远景，东方明珠在前方 |
| 01 | The Pearl | 靠近水面，仰望东方明珠 |
| 02 | The Skyline | 平移到陆家嘴三件套 |
| 03 | The Bund | 隔着江面，外滩五栋建筑全景 |
| 04 | Afterglow | 高空俯瞰，缓缓下降 |
| 05 | Footer | 夜色中的版权页 |

单个相机沿着 Catmull-Rom 样条路径穿过 6 个关键帧位置，滚动时像一个连续的推拉镜头，而不是场景切换。

## 场景（全部程序化生成）

- **东方明珠** — 混凝土立柱、天线、三个粉色球体（程序化点纹理）、三个斜撑和加色光晕。
- **黄浦江** — 大面积深色水面，垂直光带汇聚东方明珠和高楼的倒影。
- **陆家嘴三件套** — 上海中心大厦（螺旋上升）、金茂大厦（分层宝塔）、环球金融中心（带缺口的开瓶器）。
- **外滩** — 对岸一排亮着灯的低矮建筑。
- **文字标识** — 巨大的挤出 PEARL 文字，锚定首屏。
- **前景** — Canvas 生成的芦苇和树枝，固定在当前章节底部，切换时渐隐模糊。
- **后期处理** — 4 级高斯泛光、曝光、色温、暗角、噪点、sRGB 伽马。

## 操作与辅助功能

- 滚动浏览章节；导航栏 / 章节标签 / 右侧进度条可跳转到对应章节。
- 三个高楼卡片是**实时 WebGL 窗口**（裁剪渲染的子视图），不是图片。
- 调试截图：`index.html?view=0` … `?view=5` 冻结每个章节的相机（无动画循环，方便截图）。
- 调色参数：`?ex=1.3` 曝光，`?bloom=1.1` 泛光。

## 备注

- 配色：近黑、蓝炭、骨白、暖琥珀、珍珠粉。
- 字体：Onest（本地）用于拉丁文，系统中文字体用于竖排中文点缀。
- 支持减少动画和移动端（约 390×844）；自定义光标仅在精确指针设备上显示。
